# data-science-project-
This is a data science project done by UCL students within 8 weeks from Data Science Society.
This project uses Apple Inc. historical stock market data (AAPL) obtained from Yahoo Finance via the Python yfinance interface. The dataset covers the past three years of daily trading information and includes opening price, high and low prices, closing price, adjusted closing price, and trading volume. Apple stock is selected due to its relatively stable liquidity and moderate volatility, making it suitable for short-term price direction modelling.
